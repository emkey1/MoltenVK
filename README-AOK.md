# MoltenVK for iSH-AOK

The `ish-aok` branch of a fork of [MoltenVK](https://github.com/KhronosGroup/MoltenVK),
used by [iSH-AOK](https://github.com/emkey1/ish-AOK) as `deps/MoltenVK`: the
host Vulkan under the virtio-gpu render node (`/dev/dri/renderD128`), where
virglrenderer's Venus renderer replays the guest's Vulkan onto Metal.

On top of MoltenVK v1.4.2:

- `meson.build` builds the library statically, for macOS, iOS and the iOS
  simulator alike, from the consumer's cross file. iSH-AOK builds it as a
  meson subproject and merges it into its own archive. It is generated by
  `aok/gen-meson.py` from `aok/meson.build.in`; after rebasing onto a new
  release, run `python3 aok/gen-meson.py > meson.build`.
- `aok/external` holds the three dependencies the library needs, at the
  revisions `ExternalRevisions/` names, so a build needs no network:
  SPIRV-Cross (library sources), Vulkan-Headers (C headers) and cereal
  (headers). SPIRV-Tools is left out (`MVK_EXCLUDE_SPIRV_TOOLS`); it only
  disassembles SPIR-V for debug logs.

`main` tracks upstream unchanged. The upstream Xcode and CMake builds are
untouched.
